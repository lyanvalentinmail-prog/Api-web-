Uso en 30 segundos

Cualquier endpoint se consume directo con fetch, cURL o una etiqueta <img>.

# cURL
curl "https://TU-DOMINIO/api/maker/brat?text=hola%20mundo"

# JavaScript
const img = document.createElement('img');
img.src = '/api/maker/iqc?text=Hola%20desde%20un%20bot&avatar=ana';
document.body.appendChild(img);

# JSON
const data = await fetch('/api/tools/hash?text=secreto&algorithm=sha256').then(r => r.json());
